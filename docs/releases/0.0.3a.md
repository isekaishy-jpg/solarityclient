# Solarity 0.0.3a — comprehensive patch notes

**Release date:** September 8, 2026. **Previous product version:** 0.0.2a.
**Cargo version:** `0.0.3-alpha` across all nine workspace packages.
**Testing package:** Build **000036**.

This release records the work following the accepted basic locomotion milestone:
world audio and remote movement, transports, water presentation and swimming,
player health and recovery, sky and lighting, and the accompanying UI and asset
corrections. The user chose this version boundary because the final water,
lighting, and sky work overlaps the next development slice. It does not declare
all of those systems complete.

The reviewed development range is
[`295d80d8..d33d66cb`](https://github.com/isekaishy-jpg/solarityclient/compare/295d80d8..d33d66cb):
**93 commits**, comprising 79 implementation/fix commits and 14 numbered package
records, from Testing Build 000022 through 000035. The baseline is the commit
that changed the version to 0.0.2a, not its later packaging commit.
The [complete chronological ledger](0.0.3a-commits.md) accounts for every commit.
The release administration below additionally covers this version change itself.

## World audio and remote movement

- Added live zone music, introduction music, ambience, and chunk sounds, with
  authored area/subzone/WMO precedence, day/night choices, world-state conditions,
  introduction cooldowns, music delays, and explicit silence overrides.
- Added session-owned world-state packet processing. Ordered updates and
  retained values survive map replacement and feed conditional audio selection.
- Connected camera submersion and registered WMO liquid selection to underwater
  ambience. Camera and unit immersion remain separate queries.
- Added retained asynchronous music/ambience lifetimes, crossfades, cancellation,
  and revival of a fading previous selection. Removed or replaced owners cannot
  be revived by a late asset completion.
- Corrected entry into the world: character-screen music loses its repeat
  callback and fades out; FrameXML startup sound requests are suppressed in the
  native admission bracket instead of replaying together after loading.
- Corrected positional sound attenuation, including the fourfold rolloff curve,
  the taper over the final 10% of maximum distance, and silence at the cutoff.
  Initial playback applies the current listener's gain and panning before the
  first sample.
- Added model-owned game-object/doodad loops and duplicate sound admission,
  authored fade/stop policies, unit vocal ownership and attachment positioning,
  and native gain/pitch variation with shared random-stream ordering. Fixed
  looping playback and reset stale panning/pitch when backend tracks are reused.
- Wired output-device enumeration and saved device-name reconciliation, output
  quality, explicit sound-system restart, and background sound options through
  Glue and world UI. Restart retires old voices and pending loads; focus muting
  preserves their timelines. Minimized presentation continues audio servicing.
- Added retained creation splines and post-spawn monster paths, including linear
  and smooth curves, packed controls, clock wrapping, duration/speed limits,
  correction paths, stop behavior, and endpoint/target facing.
- Added an ordered remote ground/fall movement timeline, delayed-command
  admission, correction blending, collision, and animation/sound publication.
  NPC paths now drive walk/run selection from their authored speed. Local echoes,
  unknown units, removed entities, and reused GUIDs cannot inherit stale motion.
- Unified object baselines, ordinary remote commands, and paths into receive
  order, so a later packet cannot replace an earlier pending path's inputs.
  Remote jump/land audio uses the same retained unit callbacks as local movement.

## World entry, camera persistence, and collision fixes

- Added generic authored area-trigger entry. A living player's first active
  volume is retained until exit; entry sends the frozen movement heartbeat
  before the trigger notification through the encrypted writer. This enables
  server-driven instance transitions without hardcoded entrance IDs.
- Persisted ordinary camera distance and pitch in each character's local
  `config-cache.wtf`, restoring them before movement starts and saving before
  disconnect/shutdown while preserving unrelated records.
- Fixed map entry when no map-specific global light exists, using the original
  global Light row fallback. This resolved the Ragefire Chasm lighting failure.
- Fixed global WDT dungeon placement to use instance coordinates rather than
  the outdoor ADT origin offset. Ragefire Chasm can now resolve its initial
  dungeon floor instead of remaining behind the loading screen.
- Fixed a movement regression where a distant dynamic object's unloaded
  destination froze walking, jumping, and falling across the entire map.
  Only missing terrain inside the actual movement query now blocks progress;
  resident references remain usable and refresh when terrain arrives.

## Transports and passenger movement

- Added complete server game-object template replies, coalesced entry queries,
  weak instance callbacks, and session cache retention across map changes.
  Writer backpressure preserves pending requests; removed instances cannot
  consume a later reply. Replicated transport clocks retain wrapping semantics.
- Loaded the exact route, physics, position-animation, and rotation-animation
  tables while preserving authored control order and owner lookup behavior.
- Implemented type-15 transport routes: sections, station stops, dwell times,
  arrival/departure event clocks, acceleration/deceleration, route-facing,
  banking and wave motion, server period changes, and stop/resume synchronization.
- Connected route poses to live game objects, render/collision transforms, and
  shared model animation timers. Start/moving/stop transitions retain completion
  phases without restarting an unchanged route phase. Another-map samples retain
  the current local pose; the server still owns the world transfer.
- Added template-gated moving M2 and WMO map-model collision, native query masks
  and reference order, initial scale-one/yaw placement, and invalidation when a
  model, transform, map, or object lifetime changes.
- Added passenger-space collection and collision conversion, authored M2/WMO
  retention volumes, and separate boarding permission and retention rules.
- Integrated local boarding, walking aboard, switching parents, leaving, and
  landing onto moving decks. Ground/fall anchors, elapsed motion, and facing
  survive coordinate changes. Idle passengers follow the parent, and the camera
  continues to use world-facing orientation.
- Retained distinct route/passenger clocks and froze local coordinates, parent
  GUIDs, seats, and optional clock fields in outgoing transport packets. Leaving
  sends the native GUID-zero transport block; queued packets retain their
  original snapshot under writer backpressure.
- Detach local passengers while a retiring transport still owns its matrix,
  preserve the latest correction, and queue the support recheck in timestamp
  order. Replaced worlds and already-detached passengers reject stale callbacks.
- Added remote passenger prediction and transport-authored monster paths in
  parent coordinates. Idle and completed paths follow their decks; replacement
  world paths detach through the current parent transform. Immediate, queued,
  and path-driven missing-parent cases retain their distinct native behavior.
- Implemented type-11 animated transport clocks, interval reversals, key
  interpolation, parent quaternion composition, packed poses, and passenger
  phases. Their initial behavior is constructed from the original create block
  before later blocks overwrite replicated fields.
- Connected type-11 creation/state updates, late template/model admission,
  long-frame presampling, linked-passenger thresholds, and all selected model
  sequence requests. Both transport families advance on the same movement-frame
  delta and preserve their independent placement and animation state.

## Liquids, swimming, and water effects

- Added river, ocean, and WMO depth coordinates and procedural depth images,
  authored animated texture timing, water/no-specular-water/magma shader
  families, and their native lighting, alpha, saturation, and fog behavior.
- Added terrain liquid meshes with all authored vertex formats, holes, depth
  banks, UVs, and strip restarts. Runtime batches native two-by-two chunk groups,
  retains materials and texture ordinals, and submits culled water/magma with
  the current camera, environment, texture filter, and clock.
- Added WMO liquid geometry and materials for static, global-dungeon, and
  replicated placements, including portal-clipped cells, magma UV interpretation,
  interior water remapping/tint, depth columns, and private interior lighting.
  Moving placements use their current transform; the last owner retires shared
  liquid resources.
- Inserted transparent water between the appropriate M2 transparent passes,
  switching order with camera submersion. Fenced frame storage reuses liquid
  uniforms, descriptors, and depth images; uploads and retirement avoid a
  CPU-side GPU-idle wait.
- Implemented local and remote swimming through resident terrain/WMO liquids:
  height-based immersion hysteresis, deferred entry/exit commands, pitched 3D
  movement, ascent/descent, camera steering, surface jumps, and separate solid
  and water collision banks. Passenger localization and frozen movement packets
  preserve the same transitions.
- Published the immediate `IsSwimming` Lua state independently of deferred
  movement flags. Added race-authored entry/exit splash audio with native local
  priority and character/camera listener behavior.
- Added underwater light-bank selection, direct liquid light overrides, and
  packed-color depth darkening. Fixed empty authored color/scalar bands to return
  native black/zero defaults, resolving the swimming crash without treating
  missing database rows as valid data.
- Added circular and directional surface ripples/splashes, native emission
  deadlines and random draws, local/other-unit pool ownership, geometry
  collection, growth/fade/retirement, and an additive GPU pass after water.
  Authored samplers and depth bias remain independent of global filtering.
- Added creature-template querying and lifetime-safe cache publication for ripple
  suppression. Recursive model bounds, registered water height, template flags,
  and inherited area liquid policy gate emission before randomness is consumed.
- Replaced the approximate camera ray fan and fixed water clamp with the native
  primary traces, separate solid/water swept volumes, terrain/WMO liquid rays,
  final eye correction, height recovery, and surfaced/submerged pitch transitions.
  First-person distance stays zero; final eye adjustment does not overwrite the
  persistent zoom request.
- Added the process-owned underwater particulate pool, authored atlas patterns,
  liquid-dependent scale and drift, camera-relative wrapping/reseeding, and the
  `waterParticulates` console toggle. The pool survives map changes and retains
  native random-stream lifetime. Its GPU pass follows world/M2 effects with
  liquid-dependent fog, depth testing, and no depth writes.
- Added authored underwater breath, cold breath, inebriated bubbles, and walking/
  running water spray through ordinary M2 effect models. Unit registration,
  climate, depth, inebriation, foot markers, scale clamps, mouth/root attachments,
  and duplicate rules choose and place the effects.
- Prepared the shared effect bank during login so authored callbacks need no
  decoding or shader compilation. Effects retain creation clocks during delayed
  admission, appear in the current model scene, and retire with their unit.
- Corrected per-model global-sequence origins, zero-tick particle behavior, and
  effect completion. Retired effects stop new emission and mesh/ribbon draws
  while live particles continue to drain, including outside the model's bounds.

## Sky, weather, lighting, fog, and visibility

  scaling, and ordered local-light overlays. All authored sky/color channels,

- Corrected the exterior daylight ray passed to liquid shaders, restoring the

- Added the camera-relative sky gradient dome with dawn/dusk highlights and a
  fog-colored horizon, using retained geometry and reserved sky depth.
- Added procedural clouds with native noise/grain tables, octave smoothing,
  incremental texture updates, horizon opacity, and sun/moon lighting. Failed
  submission keeps changed cloud content pending for upload.
- Added the shared realm sky clock, continuous daylight direction, integer band
  time, map time overrides, and lunar calendar inputs. Startup accounts for the
  cloud constructor's random draws before later model/effect consumers.
- Wired weather packets and authored weather records to native transition

  palette blending. Direct liquid light overrides retain their separate policy.
- Added the sun and both moons with native ephemeris, billboard bases, horizon

- Added the authored star model with native night opacity, independent M2 scene

- Added up to three authored skybox slots with native replacement/overlay

  All 48 unique installed skybox models were exercised in the archive-backed

- Applied native camera fog ranges and power curves across world renderers,

- Added camera-owned WMO registration and local fog selection, including two

- Added animated M2 scene-light publication and native point/directional-light

- Added WMO floor-light interpolation and transitions for units/game objects,

- Corrected terrain/WMO diffuse texture interpretation to retain stored color

## UI, screenshots, textures, cinematics, and diagnostics

- Fixed pointer routing after Lua hover enter/leave errors. The old target no
  longer blocks later clicks or camera input; callback mutations still finish
  and errors reach the bounded diagnostics mailbox.
- Corrected frame-level draw ordering and XML/runtime font-layer inheritance.
  Breath and Fatigue labels retain their OVERLAY layer and draw after bar fills.
- Corrected inherited region scale, cross-scale anchors, Lua edge queries,
  rendering bounds, and hit testing. Added live screen clamping/insets with native
  edge precedence and corrected child anchors after clamping.
- Corrected cursor tooltips, owner/reset/preserve behavior, callback-before-cursor
  update order, and cursor conversion to unscaled UI canvas units. Unchanged
  pointer/anchor state does not repeatedly dirty retained layout.
- Implemented `Screenshot()` for Glue and world UI. It captures the next
  successfully presented frame including effects and UI, then encodes/saves on
  the owned CPU executor and dispatches the stock success/failure event.
  JPEG/TGA format and quality CVars are supported. Files go to the profile's
  `Screenshots` directory; same-second captures preserve existing files.
  Save failure leaves the client running.
- Fixed the character-rendering crash caused by applying creation eligibility
  to authored appearance lookup. Rendering now accepts all authored section
  flags and the last physical duplicate row, including the reported Orc male
  skin 17. Creation-choice restrictions remain independently enforced.
- Corrected BC1/BC2/BC3 narrow-mip block accounting so complete images retain all
  blocks. Explicitly admitted authored one-block narrow tail mips while retaining
  errors for truncated file ranges, partial blocks, and incomplete ordinary mips.
  The installed-data audit covered 111,072 BLP paths; all 866 affected textures
  with 1,097 short tails load through the corrected boundary.
- Added FFmpeg's MPEG-4 packed-B-frame unpacker before cinematic video decoding,
  preserving packet timestamps, ownership, queue draining, and end-of-stream
  order. The installed Lich King intro decodes all 4,757 video frames without the
  packed-frame warning.
- Reduced audio mixer work by eliminating repeated playback scans, redundant
  sorting, and unchanged gain writes. The recorded 128-voice debug memory-mixer
  benchmark fell from 30.95 to 9.14 ms/update; this is an isolated historical
  measurement, not an in-world FPS result.
- Bounded opt-in frame diagnostics to two-second aggregates with counts, means,
  maxima, and the worst frame. Normal Testing installs now leave frame timing
  instrumentation off. Expected sound capacity/exclusivity refusal stays quiet.

## Validation and remaining work

The commit review includes original-executable capture generators and fixtures,
decoded-asset tests, encrypted loopback sessions, real PCM output, complete stock
FrameXML execution, and offscreen D3D9/Vulkan comparisons. These are different
evidence boundaries; passing a numeric fixture does not by itself prove live
visual behavior. Historical per-commit checks are recorded in commit bodies and
the linked architecture documents. Release-time checks are recorded below.

Selected coverage added in this range includes 28 native transport routes with
6,588 placement/physics and 11,200 clock samples; 7,290 swimming trajectories;
36 original liquid shader frames compared against Vulkan; 48 installed skybox
models; and 1,440 portal traversals, 1,122 portal projections, and 108 camera-plane
sets. The latest projection/plane results compare by float bits. Other suites
use their documented geometric or pixel tolerances and are not relabeled as
bit-exact.

Remaining boundaries at this release include:

- **World visibility/lighting:** the stock camera matrix/corner adapter,
  exterior-root admission, per-model portal draw/fog routing, WMO sky visibility,
  and global sky override; terrain point-light/specular permutations, projected
  entity shadow planes, dynamic shadow-map modes, and specialized entity callbacks.
- **Weather/audio:** precipitation particle rendering and retirement, weather
  ambient audio, DSP/reverb and class-specific filters, the original high-quality
  resampler, and automatic physical-device hotplug restart.
- **Movement/transports:** ordinary transport-model animation/speed callbacks,
  swept passenger collision-push and remaining remote destruction callbacks;
  complete mounts, flight, vehicles, and other specialized movement/control
  opcode owners. The special automatic camera-dive modes remain unintegrated.
- **Player systems/UI:** general aura visuals/filtering and spell casting,
  inventory-item self-resurrection selection, active battlefield/world-cinematic
  providers, other cursor operations, corpse model rendering and world-map
  projection, indoor minimap selection, tracking/pings, and other marker/hover
  consumers. Combat-lockdown query/events do not implement secure-frame mutation
  enforcement. Local camera persistence does not implement account-data sync;
  the new session name cache does not persist `namecache.wdb`.
- **Asset/media fidelity:** short DXT tails retain the existing zero-padding
  treatment; native pixels for absent blocks remain unproven. Screenshot codecs
  do not promise byte-identical original JPEG/TGA encodings. The installed intro
  has a truncated final MP3 frame that independently triggers FFmpeg's
  `invalid new backstep -1`; playback completes, but the source defect remains.
- **Acceptance/performance:** this release does not claim complete stock visual
  parity, zero customization stalls in every scene, or achievement of the
  approximately 1,200 FPS goal. Broader live comparisons remain required.
